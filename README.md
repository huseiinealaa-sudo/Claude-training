# Claude-training

مستودع تدريبي لتعلّم Claude Code.

## الغرض

مساحة للتجريب العملي: كتابة التوجيهات، ضبط الصلاحيات والخطّافات، وتجربة سير العمل الكامل من إنشاء الفرع حتى دمج Pull Request.

## المحتويات

| الملف | الغرض |
|---|---|
| `README.md` | هذا الملف: تعريف المستودع وسير العمل |
| `CLAUDE.md` | التوجيهات وقواعد التعامل التي يقرأها Claude Code تلقائياً في كل جلسة |
| `.claude/settings.json` | صلاحيات الأدوات وخطّافاتها على نطاق المشروع |
| `.gitignore` | استبعاد ملفات النظام والمحررات والملفات المؤقتة والأسرار |

لا يحتوي المستودع على شيفرة مصدرية ولا نظام بناء ولا اختبارات.

## سير العمل

القاعدة الحاكمة: كل خطوة تحتاج موافقة مستقلة، والموافقة على خطوة لا تمتدّ إلى ما بعدها.

1. أنشئ فرعاً: `git checkout -b claude/<وصف-قصير>`
2. اعرض الـ diff قبل الكتابة إلى القرص، وانتظر الموافقة.
3. `git commit` بعد الموافقة على الـ diff.
4. `git push -u origin <اسم-الفرع>` بموافقة صريحة منفصلة.
5. افتح Pull Request نحو `main` بطلب صريح. الدمج المباشر في `main` غير مسموح.

تفصيل هذه القواعد في `CLAUDE.md`.
