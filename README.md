# تحدّي الإنجليزية الشامل

تطبيق ويبٍ لتعلّم الإنجليزية من مستوى **A2 إلى B2**، مبنيٌّ للناطقين بالعربية، يعمل بلا إنترنت ويُثبَّت على الشاشة الرئيسة في iOS كتطبيقٍ أصيل.

> **[افتح التطبيق ←](https://huseiinealaa-sudo.github.io/Claude-training/)**

---

## ما فيه

| | |
|---|---|
| **٢٦ وحدة** | مستويان: A2 → B1 شرحه بالعربية، وB1 → B2 شرحه بالإنجليزية مع سندٍ عربيّ |
| **١٨٢ درساً** | سبعة أيّام لكلّ وحدة: قاعدة · مفردات · استماع · قراءة · لغة وظيفيّة · كتابة · اختبار |
| **١٣٠٧ أسئلة** | ستّة أنواع: اختيار · ملء فراغ · ترتيب · إملاء سماعيّ · تصحيح · فهم مسموع |
| **٦٤٠ مفردة** | تدخل نظام تكرارٍ متباعد بسبعة صناديق تلقائيّاً |
| **٣٢ نصّ قراءة** | نحو ٢٠٠ كلمة لكلٍّ، مع ترجمةٍ كاملة ومفاتيح مفردات |
| **٢٤ حواراً** | خمسة عشر سطراً لكلٍّ، بثلاث سرعاتٍ للاستماع |

## ما يميّزه

**اللكنة الأمريكيّة الحقيقيّة، لا الأكاديميّة.** وحدةٌ كاملة في الصوتيّات (`Flap T`، الشوا، الربط، الإدغام)، وكتلة 🎧 في **كلّ يوم** تدرّب الأذن على ما يُقال فعلاً — `woulda`، `gonna`، `wuddy say` — لا على ما يُكتب. وأسئلة إملاءٍ تسمع فيها الاختزال وتكتب الصيغة الصحيحة.

**قفلٌ تسلسليّ.** الوحدة لا تُفتح إلّا باجتياز اختبار التي قبلها بـ٨٠٪. المنهج تراكميّ: الشرط الثالث يفترض الأوّل والثاني، والكلام المنقول الكامل يفترض المبسّط.

**تكرارٌ متباعد.** كلّ مفردةٍ تمرّ بها تدخل سبعة صناديق بفواصل `0·1·3·7·16·35·75` يوماً. الشاشة الرئيسة تقول لك كم عنصراً استحقّ اليوم.

**مدقّق كتابة.** ٢٦ قاعدةً على أخطاء الناطقين بالعربية التي يعالجها المنهج نفسه — `informations` · `said me` · `If I would have` · `discuss about` · `I am agree` · `since two years` — كلّ ملاحظةٍ تحيلك إلى وحدتها.

**مفكّرة أخطاء.** كلّ سؤالٍ تخطئ فيه يُحفظ لتراجعه.

**نسخة احتياطيّة.** تقدّمك محفوظٌ في متصفّح جهازك وحده — فشاشة `#/backup` تصدّره نصّاً أو ملفّاً وتستعيده، بما فيه اختباراتك ونصوص كتابتك.

**يعمل بلا إنترنت.** عامل خدمةٍ بسياسة «الشبكة أوّلاً ثمّ الذاكرة»: المحتوى محدَّثٌ دائماً، ويشتغل في الطائرة.

## التثبيت على iOS

1. افتح [الرابط](https://huseiinealaa-sudo.github.io/Claude-training/) في **سفاري** (لا في متصفّحٍ آخر).
2. زرّ المشاركة ← **إضافة إلى الشاشة الرئيسية**.
3. افتحه من الأيقونة — يعمل بملء الشاشة بلا شريط عنوان.

يتحدّث تلقائيّاً عند فتحه متّصلاً. إن تأخّر: أغلقه من مبدّل التطبيقات ثمّ افتحه.

## البنية

لا نظام بناء ولا حِزَم — ملفّاتٌ ساكنة وES2020 خالصة.

```
English-A2-to-B2.html   هيكل التطبيق (لا تُعِد تسميته: هو هويّة النسخة المثبَّتة)
index.html              تحويلٌ من جذر الموقع
sw.js                   عامل الخدمة
assets/app.js           المنطق كلّه
assets/app.css          التنسيق كلّه
content/course.json     خريطة الدورة
content/<unit>.json     وحدةٌ كاملة تُحمَّل عند فتحها فقط
tools/                  الاختبارات ومدقّق المحتوى
```

هيكل التطبيق ~١١٤ كيلوبايت ثابتة، وكلّ وحدة (٤٠–٥٧ كيلوبايت) لا تُحمَّل إلّا عند فتحها.

## التشغيل والاختبار

```bash
python3 -m http.server 8099
# http://127.0.0.1:8099/English-A2-to-B2.html

./tools/test-all.sh     # ١٠١ تأكيد + مسح ٦١٥ صفحة عبر ثلاثة مقاسات
```

| المجموعة | ما تفحصه |
|---|---|
| `validate.py` | بنية المحتوى كلّه مقابل ما يرسمه التطبيق فعلاً |
| `test-app.mjs` | التنقّل · التكرار المتباعد · الكتابة · مفكّرة الأخطاء · ترحيل التقدّم |
| `test-lock.mjs` | قفل التسلسل، بما فيه محاولة تخطّيه بكتابة العنوان |
| `test-features.mjs` | مدقّق الكتابة والنسخة الاحتياطيّة |
| `test-home.mjs` | الشاشة الرئيسة: ثلاثة مقاسات × ثلاث حالات قفل |
| `test-layout.mjs` | ٦١٥ صفحة: تجاوز العرض والصفحات الفارغة وأخطاء JS |

## المساهمة

`main` هو ما تخدمه GitHub Pages — فالعمل لا يصل المستخدم حتى يُدمج فيه. التطوير على فرعٍ ثمّ Pull Request. راجع `CLAUDE.md` لبنية المحتوى وقيوده قبل إضافة وحدة.
